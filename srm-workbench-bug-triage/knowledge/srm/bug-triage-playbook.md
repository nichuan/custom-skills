# 线上问题排查思路（来自交接文档）

## 1. 卡片字段展示问题
- a. 排查菜单 **单据字段映射** 中的卡片字段配置项。
- b. 看模块提供的详情接口返回数据是否有误。

## 2. 待办缺失、卡片计数有误
- a. 排查菜单 **待办与关注** 中定义的待办生成条件规则是否正确。
- b. 捞查询日志中的 **DSL 语句**，在华为云 ES 查询看待办是否生成。
- c. ES 单据权限过滤是否正确。
- 注意：待办与单据分开存，分页时筛选器条件为单据字段、排序按待办生成时间，需拿符合的单据主键重查待办并按生成时间排序。

## 3. 超级搜索查询不到单据
- a. 查询关键字的维度字段是否在配置表配置。
- b. 捞 DSL 语句分析。

## 4. 卡片条数计数有误、卡片数据和条数对不上
- 检查待办与关注定义是否对应模块有 **新老两套**，问清租户用新还是老，禁用其中一个。

## 5. 待办问题排查（代码层，来自技术文档）
- 查 ES 中待办数据，关注字段：`combineCode`(组合业务编码)、`documentId`(单据主键)、`documentKey`(组合业务对象+待办编码+单据主键)、`todoCode`(待办编码)。
- 到租户级待办定义查订阅条件 → 到数据库查对应订阅条件：
  - 一致 → 问题在待办订阅条件配置。
  - 配置没问题 → 再查待办生成代码。

## 常见异常与处理
- **ES 权限变更任务致堆外 OOM**：ES Bulk 引发，参考华为云/简书排查思路。
- **`java.io.IOException: Broken pipe`**：ES 查询/写入（消费、ES 权限更新）时报文太大（主要是 access 权限内容多）。不改造权限体系下的方案：减少与 ES 交互的报文大小、重试。
- **`java.io.IOException: Connection reset by peer`**：客户端与 ES 服务端 TCP 连接中断（类似 MySQL 8 小时闲置被关）。参考华为云 CSS 相关文档。

## 待办/权限变更与清除规则（产品整理，定位"为什么没清理"用）
1. 禁用租户级待办 → 定时脚本：待经办/工作流/按行审批会清理，待转单不清理。
2. 引用部分待办 → 定时脚本：除待转单其他会清理。
3. 修改待办订阅对象 → 定时脚本：老待办不清理，待转单/按行处理不清理也不生成，新待办不生成。
4. 子账户权限 → 加入全部后实时生效；非加入全部时增权限定时脚本生成/清理，删权限实时生效。
5. 单据权限 → 增加维度：无权限实时生效，有权限定时脚本生成；删除维度：有权限实时生效，无权限仍查不到。
6. 修改角色菜单权限 → 定时脚本：待经办/待转单/按行处理不清理。
7. 修改待办生成条件 → 定时脚本可清理。
